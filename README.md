# FOLLOW THE GREEN — version légère

Cette archive contient tout le jeu sauf la vidéo, afin de faciliter le téléchargement.

## Ajouter la vidéo

1. Prendre la vidéo originale.
2. La renommer exactement :

   `follow-the-green.mp4`

3. La placer dans le dossier `assets`, à côté de `poster.jpg`.

Le chemin final doit être :

`assets/follow-the-green.mp4`

La vidéo doit rester au format MP4. Le jeu s'arrête automatiquement après les 38 secondes utiles, même si le fichier WhatsApp contient ensuite une longue partie noire.

## Envoyer sur GitHub

Après avoir ajouté la vidéo, envoyer directement à la racine du dépôt :

- `index.html`
- `styles.css`
- `game.js`
- `README.md`
- le dossier `assets` contenant `poster.jpg` et `follow-the-green.mp4`

Dans **Settings > Pages**, sélectionner **Deploy from a branch**, `main`, puis `/(root)`.
